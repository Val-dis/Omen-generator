# omen

a tiny cli that draws a cryptic omen. no dependencies, one file.

```
$ python omen.py
$ python omen.py -n 3
$ python omen.py --seed 13
```

`--seed` makes the output repeatable, so the same seed always gives the same omen.

the word lists sit at the top of `omen.py`. add your own and it just works.
